# Crack the Code: rules

An original two-player duel in the bulls-and-cows family. Each player hides a code; take turns
guessing the other's.

| Rule            | Behaviour                                                                                                  | Default (range) |
| --------------- | ---------------------------------------------------------------------------------------------------------- | --------------- |
| Code            | Digits 0–9, **no repeats**, leading zero allowed                                                           | 4 digits (3–5)  |
| Setup           | Both lock a secret. When the setup timer ends, missing secrets are generated by the server (unique digits) | 60 s            |
| First player    | Random for the first game; **swaps on every rematch**                                                      | —               |
| Turns           | Strictly alternating                                                                                       | —               |
| Scoring         | **Bull** = right digit, right place. **Cow** = right digit, wrong place                                    | —               |
| Turn timer      | When it runs out, the turn is **used up** (counts toward the limit) and passes                             | 45 s (30–90)    |
| Guess limit     | Per player; counts guesses **and** timed-out turns                                                         | 10 (8–12)       |
| Duplicate guess | Repeating your own earlier guess is rejected (`DUPLICATE_GUESS`) and does not use the turn                 | —               |
| Equalizer       | If the **first** player cracks the code, the second gets **one last guess**. Crack it too → **draw**       | —               |
| Out of guesses  | Both players used all turns without cracking → **draw**                                                    | —               |
| Forfeit         | "Give up", or leaving the room mid-game = immediate loss                                                   | —               |
| Disconnect      | Away longer than the grace period = loss (`abandoned`)                                                     | 60 s            |
| Rematch         | Both vote → new game session in the same room, other player first                                          | —               |

**Worked example.** Secret `5831`, guess `5813`: 5 and 8 are in place (2 bulls); 1 and 3 are
present but swapped (2 cows).

## Exact end conditions

With strict alternation and equal limits, after the first player's k-th turn the second player
has used k−1 turns. So:

- First player cracks on turn k → `LAST_CHANCE`. The second player always has a turn left.
  - Second player cracks → draw (`both_cracked`).
  - Second player misses or times out → first player wins (`cracked`).
- Second player cracks on turn k → second player wins immediately (both had k turns).
- Second player's N-th turn ends without a crack → draw (`out_of_guesses`). Nobody can ever
  exceed N turns, and two idle players cannot stall forever because timeouts consume turns.
- Forfeit → `FINISHED`, reason `forfeit`. Grace expiry → `ABANDONED`, reason `abandoned`.

## Why the equalizer

Without it, going first is a real advantage. With it, both players always get the same number
of turns, so the start order stops deciding close games.
